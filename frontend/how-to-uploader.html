How to Use the OSCAR Uploader

Back to Uploader

Choose a tab below for step-by-step upload instructions.

1) Upload from your SD card root folder

  • Choose a date range of data to upload. Maximum 6 months back, up to and including today.
  • Select your SD card's root folder (not a subfolder).

The root folder must contain the always required files: Identification.crc and STR.edf.

Example SD card root structure

SDCARD/
├── Identification.crc   (required)
├── STR.edf              (required)
├── DATALOG/
└── SETTINGS/

2) Proceed to OSCAR and open Profile

Click Proceed to OSCAR. Once OSCAR opens, if all goes well, your profile should be created and the SD Card data should be imported automatically. Afterwards you should be able to see your daily view page right away.

If not, try to import your data by selecting the folder you uploaded, which should be found inside: /config/Documents/SDCARD/

3) Review your data and change settings

Once your profile is imported, you can review it and change any settings in OSCAR that you wish. Your personal OSCAR settings will be saved along with your profile data so feel free to customize it however you like.

4) Generate a sharing link

You can generate a sharing link either in OSCAR or on your uploader page. Sharing links are valid for 24 hours before they expire. At this time links can only be shared to users who have also registered with the service already. You can generate up to 5 valid links before the oldest ones are destroyed. Users who view your profile with the sharing link cannot permanently change any settings or alter your profile or data since the OSCAR session is "ephemeral".

1) Upload your CPAP SD card data first

Before uploading oximetry files, complete the SD card upload steps in the How to Upload SD Card Data tab.

2) Select your oximetry device and upload data

  1. Click Browse and select the folder that contains db_o2.db.
  2. Make sure that same folder also contains the numbered oximetry folder(s) created by your device.
  3. Upload the selected folder.

After upload, all detected files will be available in config/SDCARD/Oximetry and can be imported in OSCAR with the Wellue/Viatom import feature.

  1. Click Browse and locate the .spo2 files you want to upload.
  2. Select one or more .spo2 files, then upload.

After upload, those files will be available in config/SDCARD/Oximetry and can be imported using OSCAR's Oximetry import wizard.

Important service note

This service currently supports limited multi user access. Due to the resource burden imposed by having multiple live OSCAR clients, the service is restricted to only allowing access to a handful of users in using OSCAR at a time. If you cannot access OSCAR due to user limitations, you do not need to import your data manually right away if you dont want to. You can simply upload and generate a sharing link, or come back later import another time.

If you run into issues or have feedback, please reach out to the administrator.
